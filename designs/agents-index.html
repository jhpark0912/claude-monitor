V3.1 · 추천벤토 유지 · 실사용 보정

벤토 (태스크 · 기록 중심)

V3의 벤토 룩은 유지하되 1차 축을 에이전트 → 태스크 상태 + 작업 기록으로 전환. 에이전트는 "주 담당 1 + 나머지 칩" 소형 위젯으로 축소 → 에이전트 소수·1인 편중 실사용에 맞춤. 진행 상태 파이프라인 + 집중 태스크 리스트 + 전체 폭 작업 기록 피드.

목업 열기 →
추천 관점 — 벤토 룩을 원하면서 에이전트가 소수·1인 편중인 실사용을 반영하려면 V3.1(태스크·기록 중심)이 최적. V3(스윔레인)는 에이전트가 여럿·균등할 때만 유효. 기존 앱과의 일관성이 최우선이면 Baseline/V1(Linear), 시각적 임팩트가 목적이면 V2(글래스).

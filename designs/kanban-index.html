칸반 탭 개선 목업 비교

현재 디자인 토큰(index.css)·구조를 그대로 유지하고 두 불편함만 다르게 해결한 3가지 방향. 각 목업 우측 상단 ◐로 다크/라이트 전환.
1프로젝트 선택

드롭다운을 눌러야만 목록이 보임 → 모니터링처럼 항상 노출되는 형태로.

2플랜별 항목 구분

제목만으로 구분돼, 어떤 항목이 어떤 상황인지 한눈에 안 보임.

V1최소 변경 · 가장 안전

세그먼트 탭 + 상태 분포 점

현재 구조에서 거의 손대지 않는 보수적 안. 익숙함 최우선.

①프로젝트를 상단 가로 세그먼트 탭으로 항상 노출 (활성 수 뱃지)
②플랜 헤더에 좌측 상태색 보더 + 상태별 점·개수를 접힘 상태에도 표시
목업 열기 →
V2스택 프로그레스 트렌드

스택바 + 진행중 프리뷰

구성을 비율로 보여주는 스택 바 + '지금' 하는 일을 칩으로. 상황 파악 최강.

①활성 우선 정렬 · 진행 중 프로젝트는 항상 칩 노출, 진행 없는 것만 더보기로 여닫기 (검색 없음)
②단색 바 → 상태별 비율 스택 바 + 진행/리뷰 태스크 제목 칩 프리뷰
목업 열기 →
V3모니터링 카드 톤 정합

프로젝트 카드 + 상태 매트릭스

모니터링 그룹 카드와 가장 닮은 방향. 프로젝트별 라이브 점, 플랜별 6칸 상태 격자.

①프로젝트를 모니터링식 카드 그리드로 (플랜 수·진행 수·라이브 점)
②플랜 헤더에 6상태 미니 격자 + '지금' 진행 태스크 한 줄
목업 열기 →
